# DnsSwitcher v1.5.0

Stable Windows x64 release with configurable Tray actions, refined Main/Settings/Health/Split DNS UI, About/Help, and SHA-256 verified installer delivery.

[Полное описание на русском](https://github.com/Regstar2/dns-switcher/blob/v1.5.0/docs/releases/v1.5.0.md) · [Full release notes in English](https://github.com/Regstar2/dns-switcher/blob/v1.5.0/docs/releases/v1.5.0_EN.md)

## Главное

- configurable system-tray groups with live refresh;
- refined Main, Settings, DNS Health Failover, and Split DNS UI;
- dedicated About/Help and direct Health access from **More**;
- self-contained installer and portable ZIP;
- mandatory SHA-256 verification before installer launch.

## Установка или обновление

Скачайте `DnsSwitcher-1.5.0-win-x64-setup.exe` из **Assets**. Обновление `v1.4.1 → v1.5.0` проверено; профили и пользовательские настройки сохраняются.

Portable-вариант: `DnsSwitcher-1.5.0-win-x64.zip`.

## Проверено

- Release build и automated tests — успешно;
- UI / Tray / CLI / Agent — успешно на Windows 11 x64 VM;
- DNS Health Failover и Split DNS / NRPT — успешно;
- installer/portable и upgrade preservation — успешно;
- RU/EN, System/Light/Dark и 100%/125%/150% scaling — успешно.

## Известные проблемы

Встроенный anonymous update-check не может читать GitHub Releases, пока repository остаётся private. Пользователь с доступом к репозиторию может скачать и установить release asset вручную. В приложение не встроены GitHub credentials.

## Файлы

- `DnsSwitcher-1.5.0-win-x64-setup.exe` — Windows x64 installer;
- `DnsSwitcher-1.5.0-win-x64.zip` — Windows x64 portable package;
- `SHA256SUMS.txt` — SHA-256 для обоих binaries.
