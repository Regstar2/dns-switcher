# DnsSwitcher v1.5.0

Стабильный релиз DnsSwitcher для Windows x64. В версии `v1.5.0` обновлён интерфейс, расширены возможности системного трея, улучшены DNS Health Failover и Split DNS, добавлены окна **О приложении** и **Помощь**, а установщик и переносимая версия распространяются с контрольными суммами SHA-256.

[Полное описание на русском](https://github.com/Regstar2/dns-switcher/blob/v1.5.0/docs/releases/v1.5.0.md) · [Описание на английском](https://github.com/Regstar2/dns-switcher/blob/v1.5.0/docs/releases/v1.5.0_EN.md)

## Главное

- настраиваемые группы и действия системного трея с применением изменений без перезапуска;
- обновлённые главное окно, настройки, DNS Health Failover и Split DNS;
- отдельные окна **О приложении** и **Помощь**, а также быстрый переход к состоянию DNS из меню **Ещё**;
- локализованные русские и английские подписи в окнах состояния системного трея, DNS Health, Split DNS и Agent;
- автономный установщик для Windows x64 — отдельная установка .NET Desktop Runtime не требуется;
- переносимая версия в ZIP-архиве;
- проверка SHA-256 перед запуском установщика, загруженного встроенным механизмом обновления.

## Установка и обновление

Для обычной установки скачайте из раздела **Assets** файл:

`DnsSwitcher-1.5.0-win-x64-setup.exe`

Обновление `v1.4.1 → v1.5.0` проверено: DNS-профили и пользовательские настройки сохраняются.

Переносимая версия доступна в файле:

`DnsSwitcher-1.5.0-win-x64.zip`

Для ручной проверки целостности используйте `SHA256SUMS.txt` из этого же релиза.

## Обновления

Встроенная проверка обновлений использует GitHub Releases без встроенных GitHub-токенов или других учётных данных.

При наличии новой версии DnsSwitcher принимает только ожидаемый установщик `DnsSwitcher-<версия>-win-x64-setup.exe`, загружает `SHA256SUMS.txt` из того же релиза и сверяет SHA-256 перед запуском файла.

При ошибке проверки контрольной суммы установщик не запускается.

## Файлы релиза

- `DnsSwitcher-1.5.0-win-x64-setup.exe` — автономный установщик для Windows x64;
- `DnsSwitcher-1.5.0-win-x64.zip` — переносимая версия для Windows x64;
- `SHA256SUMS.txt` — контрольные суммы SHA-256 для установщика и ZIP-архива.
