# DnsSwitcher v1.5.0

Стабильный релиз DnsSwitcher для Windows x64. В версии `v1.5.0` обновлён интерфейс, расширено меню системного трея, добавлены окна **О приложении** и **Помощь**, улучшены DNS Health Failover и Split DNS, а installer и portable-пакет распространяются с SHA-256 checksums.

[Полное описание на русском](https://github.com/Regstar2/dns-switcher/blob/v1.5.0/docs/releases/v1.5.0.md) · [Full release notes in English](https://github.com/Regstar2/dns-switcher/blob/v1.5.0/docs/releases/v1.5.0_EN.md)

## Главное

- настраиваемые группы и действия системного трея с обновлением без перезапуска;
- обновлённые окна Main, Settings, DNS Health Failover и Split DNS;
- отдельные окна **О приложении** и **Помощь**, а также быстрый переход к Health из меню **Ещё**;
- локализованные RU/EN статусы и детальные диалоги Tray, Health, Split DNS и Agent;
- self-contained Windows x64 installer и portable ZIP — отдельная установка .NET Desktop Runtime не требуется;
- проверка SHA-256 перед запуском installer, загруженного встроенным механизмом обновления.

## Установка и обновление

Для обычной установки скачайте из **Assets**:

`DnsSwitcher-1.5.0-win-x64-setup.exe`

Обновление `v1.4.1 → v1.5.0` проверено: DNS-профили и пользовательские настройки сохраняются.

Portable-версия доступна как:

`DnsSwitcher-1.5.0-win-x64.zip`

Перед ручной установкой при необходимости сверьте SHA-256 файла с `SHA256SUMS.txt` из этого же релиза.

## Известное ограничение обновлений

Исходный GitHub repository в настоящее время private. Поэтому встроенный **anonymous** update-check через GitHub Releases не может получать release metadata и assets без GitHub authentication.

GitHub credentials в DnsSwitcher не встраиваются. Пользователь с доступом к репозиторию может скачать installer или portable package вручную и проверить файл по `SHA256SUMS.txt`.

Если release source доступен приложению без аутентификации, встроенный механизм обновления принимает только ожидаемый installer и проверяет его SHA-256 перед запуском.
