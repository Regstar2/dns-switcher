# DnsSwitcher v1.5.0

Stable Windows x64 release with configurable tray actions, refined Settings/Health/Split DNS UI, About/Help, and secure update delivery with SHA-256 verified installer handoff.

## Highlights

- configurable tray menu;
- About / Help and manual update check;
- opt-out automatic update checks;
- self-contained installer;
- installer + portable ZIP + `SHA256SUMS.txt`.
