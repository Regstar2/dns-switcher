## О релизе

- **Версия:** `v1.5.0`
- **Канал:** stable
- **Дата:** 2026-08-19
- **Предыдущая версия:** `v1.4.1`
- **Платформа:** Windows x64
- **Совместимость:** обновление поверх `v1.4.1` без изменения формата пользовательских профилей и настроек

`v1.5.0` завершает текущий desktop/tray workflow DnsSwitcher. Релиз объединяет настраиваемое меню системного трея, обновлённые основные окна, подробные About/Help, финальную локализацию RU/EN и проверенный installer/portable delivery.

## Главное

- **Настраиваемый Tray** — ненужные группы действий можно скрывать в Settings; изменения применяются без перезапуска Tray.
- **Обновлённый интерфейс** — переработаны Main, Settings, DNS Health Failover и Split DNS без изменения их сетевых контрактов.
- **Health / About / Help** — основные сервисные разделы доступны напрямую из меню **Ещё**.
- **Безопасный installer delivery** — новая версия выбирается по stable SemVer, а скачанный installer запускается только после проверки SHA-256.
- **Self-contained доставка** — installer и portable ZIP не требуют отдельной установки .NET Desktop Runtime.

## Изменения

### Добавлено

- Настройки видимости групп системного tray-меню с backward-compatible defaults и live reload.
- Отдельные окна **О приложении** и **Помощь** с RU/EN локализацией.
- Прямые пункты Health, About и Help в меню **Ещё** главного окна.
- Ручная проверка обновлений и отключаемая автоматическая проверка из Tray.
- Stable SemVer selection с исключением draft/prerelease releases.
- Строгий выбор `DnsSwitcher-<version>-win-x64-setup.exe` и `SHA256SUMS.txt`.
- Windows CI и release workflow, связывающие build/tests, installer, portable package и checksums с одним commit.

### Изменено

- Обновлены Main, Settings, DNS Health Failover и Split DNS UI.
- Детальные Tray-диалоги статуса, Health, Split DNS и Agent приведены к единой RU/EN локализации.
- Версия приложения берётся из assembly metadata, канонический source — `Directory.Build.props`.
- Installer и portable delivery используют self-contained публикацию.
- README и release-документация приведены к финальному stable-состоянию `v1.5.0`.

### Исправлено

- Убраны дублированные знаки пунктуации в локализованных Tray status/details.
- Installer больше не требует отдельного .NET Desktop Runtime на целевой машине.
- Packaging сохраняет bilingual README и screenshots, используемые документацией package.

### Безопасность

- Update client не содержит PAT, OAuth token или другого встроенного GitHub credential.
- Installer не запускается при отсутствии ожидаемого checksum entry или при SHA-256 mismatch.
- Update delivery принимает только ожидаемые HTTPS GitHub release URLs настроенного репозитория.

## Установка и обновление

### Новая установка

1. Откройте [GitHub Release v1.5.0](https://github.com/Regstar2/dns-switcher/releases/tag/v1.5.0).
2. Скачайте `DnsSwitcher-1.5.0-win-x64-setup.exe`.
3. При необходимости сверите SHA-256 с `SHA256SUMS.txt`.
4. Запустите installer и завершите установку.
5. Откройте DnsSwitcher и убедитесь, что в **О приложении** отображается версия `1.5.0`.

Portable-вариант: `DnsSwitcher-1.5.0-win-x64.zip`.

### Обновление

Проверенный путь обновления:

```text
v1.4.1 → v1.5.0
```

1. Закройте UI и Tray либо разрешите installer закрыть запущенные экземпляры.
2. Запустите installer `v1.5.0` поверх существующей установки.
3. Installer обновит файлы приложения и перерегистрирует Agent runtime path.
4. Запустите приложение и проверьте версию `1.5.0`.
5. Проверьте сохранность профилей и пользовательских настроек.

Сохраняются:

- DNS profiles;
- app/UI preferences;
- Tray settings;
- DNS Health settings/state;
- Split DNS rules;
- Agent installation path обновляется на текущую установленную версию.

Перезагрузка Windows для обычного обновления не требуется.

### Автоматическая проверка обновлений

В Settings доступна ручная проверка, а Tray может автоматически проверять stable channel; automatic check можно отключить. DnsSwitcher не перезаписывает собственные binaries: после проверки SHA-256 запускается внешний Inno Setup installer через стандартный Windows/UAC flow.

### Откат

При необходимости удалите `v1.5.0` и установите предыдущий installer вручную. Перед ручным откатом рекомендуется сохранить `data/config/`; форматы профилей и основных настроек в `v1.5.0` не менялись.

## Известные ограничения

Split DNS зависит от Windows NRPT и может обходиться приложениями с собственным DNS/DoH stack.

Встроенная проверка обновлений использует только публично читаемые GitHub Releases без embedded credentials. Если release source недоступен anonymous client, приложение сообщает nonfatal update-source/network failure, а release asset можно установить вручную после проверки SHA-256.

## Артефакты

| Файл | Платформа | Архитектура | Назначение |
|---|---|---|---|
| `DnsSwitcher-1.5.0-win-x64-setup.exe` | Windows | x64 | Обычная установка и обновление |
| `DnsSwitcher-1.5.0-win-x64.zip` | Windows | x64 | Portable package |
| `SHA256SUMS.txt` | — | — | Канонические SHA-256 для installer и ZIP |

Фактические checksums вычисляются release workflow из финальных файлов и публикуются в `SHA256SUMS.txt` того же GitHub Release. Значения не копируются в этот документ заранее, чтобы не выдавать hash предыдущего candidate за hash финального release asset.
