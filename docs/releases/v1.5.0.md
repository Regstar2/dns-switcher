# DnsSwitcher v1.5.0

**Русский** · [English](v1.5.0_EN.md)

Статус: финальный release candidate; stable tag/release ещё не опубликован.

## Главное

`v1.5.0` завершает текущий Windows desktop/tray workflow: настройки tray, обновлённые основные окна, прямые разделы Health / О приложении / Помощь из меню «Ещё» и безопасный update-delivery path без встроенных GitHub credentials.

## Что нового

- настраиваемые группы системного tray-меню с live reload;
- переработанные Main, Settings, DNS Health Failover и Split DNS UI без изменения их network contracts;
- прямой переход в Health из главного меню **Ещё**;
- отдельное окно **О приложении** с фактической версией, описанием возможностей/архитектуры, лицензией MIT и ссылкой на GitHub;
- отдельное подробное окно **Помощь** с практическим описанием DNS-профилей, адаптеров, диагностики, Health Failover, Split DNS, Agent, Tray, импорта/экспорта, настроек, обновлений, Config и Logs;
- локализованные RU/EN подписи в детальных Tray-диалогах статуса, Health, Split DNS и Agent;
- установленная версия берётся из assembly metadata;
- manual update check и отключаемая automatic check из Tray;
- stable SemVer selection без draft/prerelease;
- строгий выбор Windows x64 installer asset;
- загрузка installer во временный каталог и обязательная проверка `SHA256SUMS.txt`;
- self-contained installer и portable delivery;
- общий Windows CI и exact-commit release-candidate workflow.

## Обновление

После публикации установленная версия должна обновляться через официальный Inno Setup installer. При update check новая версия предлагается пользователю, но установка не является обязательной и может быть отложена.

Update client не содержит PAT/OAuth/API secret. Пока основной GitHub repository private, production source обновлений недоступен анонимно — это release blocker, а не скрытый credential workaround.

## Проверки

Предыдущая beta candidate automation зафиксировала Release build, unit/integration tests и packaging evidence для beta commit. Пользователь закрыл beta validation phase; исторические `NOT RUN` записи не переписываются задним числом.

Финальный candidate должен отдельно пройти `.github/workflows/ci.yml` и `.github/workflows/release-candidate.yml` на exact final commit. Новый About/Help/Update UI имеет отдельный manual smoke plan: [`../testing/v1.5.0-final-smoke.md`](../testing/v1.5.0-final-smoke.md).

## Известные ограничения

- production update source: `BLOCKED`, пока repository/release source не читается анонимно по HTTPS;
- Split DNS остаётся NRPT-based и может обходиться приложениями со своим DNS/DoH stack;
- точная минимальная версия Windows не закреплена отдельным project property.

## Артефакты

После финальной сборки:

```text
DnsSwitcher-1.5.0-win-x64-setup.exe
DnsSwitcher-1.5.0-win-x64.zip
SHA256SUMS.txt
```

Артефакты должны быть собраны из одного exact release commit.

## SHA-256

Канонические значения публикуются в `SHA256SUMS.txt`, созданном final release workflow из фактических installer/portable файлов. Значения не вписываются в этот документ до публикации, чтобы не выдавать candidate hash за stable release hash.
