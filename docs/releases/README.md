# Releases

Для каждой опубликованной версии поддерживаются два файла:

```text
vX.Y.Z.md       — русский, основной
vX.Y.Z_EN.md    — English
```

Release notes описывают пользовательские изменения, установку или обновление, выполненные проверки, известные проблемы и артефакты. Они не заменяют [`CHANGELOG.md`](../../CHANGELOG.md).
