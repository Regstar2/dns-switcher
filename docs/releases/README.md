# Releases

Для каждого нового опубликованного релиза поддерживаются две синхронные версии:

```text
vX.Y.Z.md       — русский, основной
vX.Y.Z_EN.md    — English
```

Release notes описывают пользовательские изменения, установку/обновление, реально выполненные проверки, известные проблемы и артефакты. Они не заменяют [`CHANGELOG.md`](../../CHANGELOG.md).

## Legacy-ограничение v1.4.1

Полные release notes и текущая MIT License были добавлены в `main` после публикации исторического tag `v1.4.1`. Tag и assets не изменяются.

Из-за этого полные notes для `v1.4.1` нельзя сделать корректно tag-relative без переписывания истории. Текущие файлы в `main` являются документированием опубликованной версии после факта.

Для следующих релизов порядок другой: RU/EN release notes и все публичные ссылки должны попасть в release commit до создания tag, после чего краткий GitHub Release body должен ссылаться именно на файлы из этого tag.
