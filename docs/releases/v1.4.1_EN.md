## About this release

`v1.4.1` synchronizes the source, portable package, installer, and desktop component lookup paths. It does not add user-facing functionality beyond `v1.4.0`.

## Highlights

- unified `1.4.1` version metadata and release script defaults;
- updated portable and installer artifact names and directories;
- support for `artifacts/release/v1.4.1/` when locating sibling desktop executables.

## Changes

### Changed

- `Version`, `FileVersion`, `AssemblyVersion`, and `InformationalVersion` were updated to `1.4.1`;
- default values in `publish-release.ps1` and `build-installer.ps1` were updated to `1.4.1`;
- documentation and the release checklist now use `v1.4.1` artifact paths and names.

## Installation and updating

### New installation

Use the `win-x64` portable ZIP or installer EXE when those assets are published in GitHub Releases. Source build instructions are available in [`README_EN.md`](../../README_EN.md).

### Updating

Back up `data/config/` before replacing a portable build. For an installed version, use the new installer and reinstall the agent when required.

### Rollback

Return to the previous package and restore a compatible `data/config/` backup. The changelog does not declare a configuration format change for `v1.4.1`.

## Verification

The release commit updated metadata, scripts, documentation, and a package layout test path. Builds and tests were not rerun while preparing this document.

## Known issues

- Windows only;
- Split DNS can be bypassed by applications using their own DNS/DoH stack;
- the CLI is not fully localized;
- current UI screenshots are not published.
