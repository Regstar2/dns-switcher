## О релизе

`v1.4.1` — совместимый patch-релиз для Windows. Версия синхронизирует метаданные приложения, значения по умолчанию в release scripts и пути артефактов. Пользовательская функциональность относительно `v1.4.0` не расширялась, изменение формата `profiles.json` не заявлено, отдельная миграция не требуется.

Этот документ приведён к текущему стандарту release notes после публикации версии. Содержимое tag `v1.4.1` не изменялось. MIT License и текущие полные release notes добавлены в ветку разработки позже и отсутствуют непосредственно в историческом tag.

## Главное

- Версия `1.4.1` согласована в assembly metadata, portable packaging и installer tooling исторического tag.
- Portable ZIP и installer EXE опубликованы для Windows x64.
- Desktop-компоненты в `v1.4.1` учитывают package layout `artifacts/release/v1.4.1/`.

## Установка и обновление

### Новая установка

1. Откройте [GitHub Release `v1.4.1`](../../releases/tag/v1.4.1).
2. Для Windows x64 выберите portable ZIP или installer EXE.
3. Исторический build script `v1.4.1` использует framework-dependent publishing по умолчанию, если `-SelfContained` не был передан; фактический режим опубликованных binaries в рамках этой документационной ревизии повторно не проверялся.
4. Запустите `DnsSwitcher.Ui.exe` либо установленное приложение и проверьте, что открывается список DNS-профилей.

### Обновление

Поддерживаемый по release scope путь — с `v1.4.0` на `v1.4.1`.

1. Создайте резервную копию `data/config/`.
2. Остановите Windows Agent, если он установлен и запущен.
3. Для portable-варианта распакуйте новую версию в отдельную папку и перенесите сохранённый каталог `data/`.
4. Для установленного варианта запустите installer `v1.4.1`; при необходимости переустановите Agent штатной командой приложения.
5. Проверьте выбранный профиль, адаптер и текущий DNS status.

Изменение формата конфигурации и обязательная перезагрузка Windows для `v1.4.1` не заявлены. Фактическое обновление из финального asset при поздней ревизии release notes не выполнялось.

### Откат

1. Остановите Agent.
2. Верните package или installer предыдущей версии.
3. Восстановите резервную копию `data/config/`.
4. Повторно проверьте профиль, адаптер и DNS status.

Сценарий отката не проверялся на финальных release assets при поздней ревизии документации.

## Известные проблемы

Критические известные проблемы, зафиксированные открытыми GitHub issues на 2026-08-17, не обнаружены. Это текущая проверка issue tracker, а не утверждение о состоянии tracker в день публикации релиза.

Остаются документированные ограничения:

- приложение поддерживает только Windows;
- установка Agent и прямое изменение DNS требуют прав администратора;
- Split DNS основан на Windows NRPT и может обходиться приложениями с собственным DNS/DoH stack;
- CLI локализован не полностью;
- актуальные screenshots интерфейса не опубликованы;
- финальные assets, установка, обновление и откат не были повторно выполнены при поздней ревизии notes.
