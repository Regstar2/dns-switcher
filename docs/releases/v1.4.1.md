## О релизе

`v1.4.1` — совместимый stable patch-релиз для Windows. Версия синхронизирует метаданные приложения, значения по умолчанию в release scripts и пути артефактов. Пользовательская функциональность относительно `v1.4.0` не расширялась, изменение формата `profiles.json` не заявлено, отдельная миграция не требуется.

Этот документ приведён к актуальному стандарту release notes после публикации версии. Содержимое tag `v1.4.1` не изменялось. MIT-лицензия добавлена в текущую ветку разработки позже и отсутствует в историческом tag.

## Главное

- Версия `1.4.1` согласована в assembly metadata, portable packaging и installer tooling.
- Portable ZIP и installer EXE используют предсказуемые каталоги и имена с `v1.4.1`.
- Desktop-компоненты могут обнаруживаться внутри package layout `artifacts/release/v1.4.1/`.

- Поиск соседних desktop executable учитывает package path версии `v1.4.1`.

## Установка и обновление

### Новая установка

1. Откройте [GitHub Release `v1.4.1`](../../releases/tag/v1.4.1).
2. Для обычного запуска на Windows x64 выберите portable ZIP или installer EXE, если соответствующий asset опубликован.
3. Для framework-dependent package требуется совместимая среда выполнения .NET 10.
4. Запустите `DnsSwitcher.Ui.exe` либо установленное приложение и проверьте, что открывается список DNS-профилей.

Финальные assets и новая установка из них в рамках обновления этого документа не проверялись.

### Обновление

Поддерживаемый путь обновления по release scope — с `v1.4.0` на `v1.4.1`.

1. Создайте резервную копию `data/config/`.
2. Остановите Windows Agent, если он установлен и запущен.
3. Для portable-варианта распакуйте новую версию в отдельную папку и перенесите сохранённый каталог `data/`.
4. Для установленного варианта запустите installer `v1.4.1`; при необходимости переустановите Agent штатной командой приложения.
5. Проверьте выбранный профиль, адаптер и текущий DNS status.

Изменение формата конфигурации и обязательная перезагрузка Windows для `v1.4.1` не заявлены. Фактическое обновление из финального asset в рамках этой документационной работы не выполнялось.

### Откат

1. Остановите Agent.
2. Верните package или installer предыдущей версии.
3. Восстановите резервную копию `data/config/`.
4. Повторно проверьте профиль, адаптер и DNS status.

Сценарий отката не проверялся на финальных release assets.

## Известные проблемы

Открытые GitHub issues при обновлении документа не найдены. В документации проекта зафиксированы следующие ограничения:

- приложение поддерживает только Windows;
- установка Agent и прямое изменение DNS требуют прав администратора;
- Split DNS основан на Windows NRPT и может обходиться приложениями с собственным DNS/DoH stack;
- CLI локализован не полностью;
- актуальные screenshots интерфейса не опубликованы;
- финальные assets, установка, обновление и откат не были повторно проверены при подготовке этих release notes.
