## О релизе

`v1.4.1` синхронизирует версию исходников, portable-пакета, установщика и путей поиска desktop-компонентов. Пользовательская функциональность относительно `v1.4.0` не расширялась.

## Главное

- единая версия `1.4.1` в assembly metadata и release scripts;
- обновлённые имена и каталоги portable- и installer-артефактов;
- поддержка пути `artifacts/release/v1.4.1/` при поиске соседних desktop executable.

## Изменения

### Изменено

- `Version`, `FileVersion`, `AssemblyVersion` и `InformationalVersion` обновлены до `1.4.1`;
- значения по умолчанию в `publish-release.ps1` и `build-installer.ps1` обновлены до `1.4.1`;
- документация и release checklist используют пути и имена артефактов `v1.4.1`.

## Установка и обновление

### Новая установка

Используйте portable ZIP или installer EXE для `win-x64`, если они опубликованы в GitHub Releases. Сборка из исходников описана в [`README.md`](../../README.md).

### Обновление

Перед заменой portable-сборки создайте резервную копию `data/config/`. Для установленной версии используйте новый установщик и при необходимости переустановите агент.

### Откат

Вернитесь к предыдущему пакету и восстановите совместимую копию `data/config/`. Изменения формата конфигурации в changelog для `v1.4.1` не заявлены.

## Проверено

В release commit были добавлены изменения метаданных, scripts, документации и тестового пути package layout. Повторный запуск сборки и тестов в рамках подготовки этого документа не выполнялся.

## Известные проблемы

- приложение поддерживает только Windows;
- Split DNS может обходиться приложениями с собственным DNS/DoH;
- CLI локализован не полностью;
- актуальные скриншоты интерфейса не опубликованы.
