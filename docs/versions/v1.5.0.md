# DnsSwitcher v1.5.0

Статус: **stable**  
Дата: **2026-08-19**  
Предыдущая версия: **v1.4.1**

## Scope

- configurable Tray menu;
- Main / Settings / DNS Health / Split DNS UI refinement;
- About / Help / More navigation;
- RU/EN localization completion;
- manual and opt-out automatic update checks;
- stable SemVer selection and verified installer delivery;
- self-contained installer + portable ZIP + `SHA256SUMS.txt`;
- final Windows validation and release documentation.

## Validation

Финальная Windows matrix и smoke завершены без release-blocking дефектов:

- UI / Tray / CLI;
- DNS apply/reset/status/diagnostics;
- Windows Agent / Named Pipes;
- DNS Health Failover;
- Split DNS / NRPT;
- installer / portable / upgrade / uninstall;
- Tray customization;
- RU/EN, themes и DPI scaling.

Evidence: [`../testing/manual-test-plan.md`](../testing/manual-test-plan.md) и [`../testing/v1.5.0-final-smoke.md`](../testing/v1.5.0-final-smoke.md).

## Delivery

Stable assets:

```text
DnsSwitcher-1.5.0-win-x64-setup.exe
DnsSwitcher-1.5.0-win-x64.zip
SHA256SUMS.txt
```

Assets создаются одним publish workflow из exact release commit. Release workflow повторяет restore/build/test перед packaging и публикацией.

## Known limitation

Встроенный update-check использует anonymous GitHub Releases source и не содержит credentials. Если release source недоступен анонимно, пользователь может установить release asset вручную после проверки SHA-256.
