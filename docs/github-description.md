# GitHub About

## Short description

Portable Windows DNS switcher with CLI, desktop UI, tray client, profile editing, and DNS/site diagnostics.

## Extended description

DnsSwitcher is a Windows-first DNS profile manager built around a shared core with three user-facing clients: CLI, desktop UI, and tray.
It supports fast DNS profile switching, DHCP reset, current DNS status detection, UI profile editing/import/export, DNS diagnostics, site accessibility checks, profile benchmarking, portable config/log storage, i18n, light/dark themes, and a privileged Windows agent for DNS changes without requiring elevation on every tray/UI action.
