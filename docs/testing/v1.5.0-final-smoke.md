# v1.5.0 final About / Help / Update smoke

Этот план относится только к новой финальной функциональности. Он не переписывает результаты предыдущих DNS Health / Split DNS / Agent validation phases.

Статус при создании документа: `Не выполнено`.

## Environment evidence

Перед PASS записать:

- Windows version/build;
- tested commit SHA;
- installer filename и SHA-256;
- дату проверки.

## Main → More navigation

1. Установить exact candidate installer и открыть Main Window.
2. Открыть нижнее меню **Ещё / More**.
3. Проверить отдельный пункт **Health** и убедиться, что он открывает существующее окно DNS Health Failover settings.
4. Проверить отдельный пункт **О приложении / About** и убедиться, что открывается самостоятельное окно About.
5. Проверить отдельный пункт **Помощь / Help** и убедиться, что открывается самостоятельное прокручиваемое окно Help.
6. Проверить RU/EN локализацию названий новых пунктов меню.
7. Убедиться, что существующие Open Config/Open Logs/Split DNS пункты не потеряны и продолжают открываться.

## About

1. Открыть **Ещё / More → О приложении / About**.
2. Проверить, что показана фактическая версия `1.5.0`, а не hardcoded XAML placeholder.
3. Проверить подробное описание основных возможностей, архитектурной роли Agent/update verification и MIT License.
4. Проверить RU/EN и System/Light/Dark.
5. Нажать GitHub и проверить canonical repository URL.
6. Проверить отсутствие crash при невозможности открыть browser.

## Help

1. Открыть **Ещё / More → Помощь / Help**.
2. Проверить scrolling и отсутствие обрезания текста.
3. Проверить наличие и читаемость разделов:
   - DNS profiles;
   - network adapter selection;
   - checks/diagnostics;
   - DNS Health/failover;
   - Split DNS;
   - Agent;
   - system Tray;
   - import/export;
   - Settings;
   - updates;
   - Config/Logs.
4. Убедиться, что Help объясняет не только назначение, но и когда применять функции и важные ограничения: Health thresholds/cooldown, Split DNS/NRPT и DoH bypass, Agent privileges, tray visibility, update checksum verification.
5. Проверить RU/EN и System/Light/Dark.

## Preferences

1. Убедиться, что automatic update check включён по default на новом config.
2. Отключить, Save, перезапустить UI/Tray и проверить сохранение.
3. Включить обратно и проверить сохранение.
4. Подложить legacy `app-preferences.json` без нового поля: automatic check должен получить backward-compatible default `true`.

## Manual update check

1. Запустить ручную проверку при рабочем release source.
2. UI не должен зависнуть.
3. Current version показывает локализованный up-to-date result.
4. HTTP/network failure показывает nonfatal локализованную ошибку.
5. Stable channel не должен предлагать draft/beta/rc release.

## Installer delivery

Выполняется только при publicly readable trusted release source.

1. Проверить strict asset name `DnsSwitcher-<version>-win-x64-setup.exe`.
2. Скачать release installer и `SHA256SUMS.txt`.
3. На заведомо повреждённом payload получить checksum failure и убедиться, что installer не запущен.
4. На валидном payload проверить запуск Inno Setup/UAC.
5. Отменить UAC и проверить nonfatal localized result.

## Upgrade preservation

```text

app preferences
tray settings
Health settings
Split DNS settings
Agent path
```
