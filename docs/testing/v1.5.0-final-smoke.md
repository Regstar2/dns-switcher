# v1.5.0 final About / Update smoke

Этот план относится только к новой финальной функциональности. Он не переписывает результаты предыдущих DNS Health / Split DNS / Agent validation phases.

Статус при создании документа: `Не выполнено`.

## Environment evidence

Перед PASS записать:

- Windows version/build;
- tested commit SHA;
- installer filename и SHA-256;
- дату проверки.

## About / Help

1. Установить exact candidate installer.
2. Открыть Settings → About.
3. Проверить, что показана фактическая версия `1.5.0`, а не hardcoded XAML placeholder.
4. Проверить RU/EN и System/Light/Dark.
5. Нажать GitHub и проверить canonical repository URL.
6. Проверить отсутствие crash при невозможности открыть browser.

## Preferences

1. Убедиться, что automatic update check включён по default на новом config.
2. Отключить, Save, перезапустить UI/Tray и проверить сохранение.
3. Включить обратно и проверить сохранение.
4. Подложить legacy `app-preferences.json` без нового поля: automatic check должен получить backward-compatible default `true`.

## Manual update check

1. Запустить ручную проверку при рабочем release source.
2. UI не должен зависнуть.
3. Current version показывает локализованный up-to-date result.
4. HTTP/network failure показывает nonfatal локализованную ошибку.
5. Stable channel не должен предлагать draft/beta/rc release.

## Installer delivery

Выполняется только при publicly readable trusted release source.

1. Проверить strict asset name `DnsSwitcher-<version>-win-x64-setup.exe`.
2. Скачать release installer и `SHA256SUMS.txt`.
3. На заведомо повреждённом payload получить checksum failure и убедиться, что installer не запущен.
4. На валидном payload проверить запуск Inno Setup/UAC.
5. Отменить UAC и проверить nonfatal localized result.

## Upgrade preservation

При установке поверх принятой предыдущей версии проверить сохранность:

```text
profiles
app preferences
tray settings
Health settings
Split DNS settings
Agent path
```

## Settings layout

Проверить новые секции на 100%, 125%, 150% scaling, keyboard navigation и scrolling без обрезания RU/EN текста.

## Exit criteria

PASS можно поставить только с фактическим evidence. Пока production release source private или отсутствуют реальные screenshots, соответствующие stable release gates остаются BLOCKED независимо от automated unit tests.
