# Документация DnsSwitcher

Публичная документация проекта разделена по назначению:

- [`architecture/`](architecture/README.md) — компоненты, зависимости и архитектурные решения;
- [`product/`](product/README.md) — назначение и границы продукта;
- [`releases/`](releases/README.md) — двуязычные заметки к версиям;
- [`testing/`](testing/README.md) — автоматические и ручные проверки;
- [`versions/`](versions/README.md) — индекс версий и критерии готовности;
- [`profiles.example.json`](profiles.example.json) — пример конфигурации DNS-профилей;
- [`ipc-integration-tests.md`](ipc-integration-tests.md) — интеграционные проверки Named Pipes.

Документы по установке и поставке пока находятся в корне репозитория, чтобы не ломать существующие ссылки.
