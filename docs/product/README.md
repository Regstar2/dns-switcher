# Продукт

DnsSwitcher решает задачу быстрого и воспроизводимого переключения DNS-настроек в Windows через несколько клиентов с общей логикой.

Текущие границы продукта:

- Windows-first desktop utility;
- локальная конфигурация без обязательного внешнего сервера;
- portable и installer сценарии поставки;
- DNS-профили, диагностика, Health Failover и NRPT-based Split DNS;
- отсутствие заявленной поддержки других ОС.

Планы следует отделять от уже реализованных возможностей и фиксировать отдельными документами или issue.
