# Продукт

DnsSwitcher решает задачу воспроизводимого переключения DNS-настроек в Windows через несколько клиентов с общей логикой.

Документы:

- [`idea.md`](idea.md) — ретроспективно подтверждённая идея, аудитория, MVP и риски;
- [`feasibility.md`](feasibility.md) — фактическая проверка реализуемости без выдуманного исторического market research;
- [`mvp-scope.md`](mvp-scope.md) — границы первой зафиксированной версии и то, что появилось позднее;
- [`roadmap.md`](roadmap.md) — только подтверждённый план; при отсутствии утверждённых будущих версий это указано прямо.

Текущие границы продукта:

- Windows desktop utility;
- локальная конфигурация без обязательного внешнего сервера;
- portable и installer сценарии поставки;
- DNS-профили, диагностика, Health Failover и NRPT-based Split DNS;
- отсутствие заявленной поддержки других ОС.
