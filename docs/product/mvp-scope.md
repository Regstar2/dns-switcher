# Границы MVP

DnsSwitcher давно находится за пределами первоначального MVP. Этот документ описывает MVP ретроспективно по `CHANGELOG.md` и не заменяет неизвестный исходный план.

## Главный сценарий

Пользователь выбирает сетевой адаптер и DNS-профиль, применяет его, проверяет результат и может вернуть автоматический DNS.

## Минимальные интерфейсы

В первой зафиксированной версии `1.0.0` уже присутствовали:

- CLI;
- desktop UI;
- tray;
- Windows Agent для привилегированных операций.

Репозиторий не содержит более раннего опубликованного scope, который позволил бы достоверно сузить этот набор.

## Минимальная модель данных

Основой служат DNS-профили, информация о сетевом адаптере и результаты диагностических проверок. Конкретные текущие модели определены в `DnsSwitcher.Core`.

## Хранение

Конфигурация и логи хранятся локально рядом с приложением в `data/`.

## Проверка результата

Для MVP фактически были доступны:

- определение текущего DNS;
- DNS diagnostics;
- site connectivity diagnostics;
- unit tests основных правил;
- возврат к автоматической конфигурации.

## Обработка ошибок

`CHANGELOG.md` для версии `1.0.0` фиксирует friendly error formatting для распространённых операционных ошибок. Более точный исходный MVP contract по error cases отдельно не зафиксирован и не восстанавливается задним числом.

## Вне MVP, но реализовано позднее

По changelog позднее были добавлены или расширены:

- UI-редактирование, import/export профилей;
- локализация и theme support;
- DNS benchmark;
- Windows Agent management;
- DNS Health Failover;
- Split DNS через NRPT;
- installer track.

## Что не восстанавливается

Не восстанавливаются без источников:

- первоначальные оценки сроков;
- исходный backlog;
- формальные acceptance criteria;
- отвергнутые альтернативы;
- будущие версии, которых нет в подтверждённом плане.
