# Дорожная карта

В текущем репозитории не найден утверждённый roadmap будущих версий DnsSwitcher. Этот документ намеренно не придумывает номера версий, сроки или функции.

## Подтверждённое состояние

- последний опубликованный GitHub Release: `v1.4.1`;
- в `main` есть unreleased maintenance-изменения после `v1.4.1`;
- открытые GitHub issues на момент ревизии 2026-08-17 не обнаружены;
- новая версия только ради текущей документационной миграции не создаётся.

## Как добавлять будущие пункты

Будущий пункт roadmap должен появляться только при наличии подтверждённого решения и содержать:

1. конкретную пользовательскую или техническую проблему;
2. ограниченный scope;
3. критерии готовности;
4. способ проверки;
5. связь с issue или version document, если они используются.

Идея не становится частью roadmap автоматически только потому, что она технически возможна.

## Не зафиксировано

На 2026-08-17 в репозитории не подтверждены:

- номер следующего релиза;
- дата следующего релиза;
- обязательный список новых функций;
- решение о переносе на другую ОС;
- решение о смене installer-технологии.
