# README review checklist

Перед stable release:

- [ ] `README.md` и `README_EN.md` синхронны по структуре и фактам.
- [ ] Версия и release badge актуальны.
- [ ] Installation соответствует фактическим installer/portable assets.
- [ ] Update section соответствует реальному update flow/fallback.
- [ ] Нет утверждений о несуществующей CI/update capability.
- [ ] Screenshots реальные, актуальные и не содержат приватных данных.
- [ ] Ограничения отражают текущую реализацию.
- [ ] Links указывают на существующие документы/tag/release, где требуется.
- [ ] Нет placeholders, secrets и локальных путей пользователя.
