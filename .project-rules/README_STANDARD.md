# README standard

DnsSwitcher поддерживает две синхронные README:

- `README.md` — русский;
- `README_EN.md` — English.

Обе версии должны совпадать по структуре и фактам.

Минимально отражать:

1. что делает DnsSwitcher;
2. поддерживаемую платформу;
3. текущую stable version/release status;
4. установку и portable package;
5. основные возможности без дублирования полной архитектуры;
6. update behavior и его фактические ограничения;
7. screenshots только если это реальные снимки текущей версии;
8. ссылки на документацию, changelog и license.

Нельзя публиковать badge или statement о CI/release/update, если он не соответствует фактическому repository state.
