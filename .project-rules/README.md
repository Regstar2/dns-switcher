# Project rules

Этот каталог содержит repo-local правила DnsSwitcher, адаптированные из `universal_project_rules_template_v9`.

Приоритет задаёт `AGENTS.md`. Правила применяются только там, где они релевантны фактическому Windows desktop-проекту.

- `PROJECT_NAMING.md` — имена и идентификаторы.
- `DEVELOPMENT_WORKFLOW.md` — рабочий цикл и проверки.
- `ENGINEERING_PRINCIPLES.md` — архитектурные и кодовые ограничения.
- `AI_TEXT_GUARDRAILS.md` — требования к достоверности текста.
- `README_STANDARD.md` / `README_REVIEW_CHECKLIST.md` — RU/EN README.
- `RELEASE_STANDARD.md` / `RELEASE_REVIEW_CHECKLIST.md` — versioning/release notes/assets.
- `AUTO_UPDATE_STANDARD.md` — update delivery.
- `LOCALIZATION_STANDARD.md` — RU/EN и fallback.
