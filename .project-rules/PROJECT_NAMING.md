# Project naming

## Canonical names

- Product: `DnsSwitcher`
- Repository: `dns-switcher`
- Solution: `DnsSwitcher.sln`
- Namespace prefix: `DnsSwitcher`
- Windows service: `DnsSwitcherAgent`
- Installer product/AppId: сохраняются существующими.

Не переименовывать package/application/service identifiers автоматически вслед за repository naming. Любое такое изменение требует отдельной migration-задачи.

Новые ветки используют понятные kebab-case имена. Release branch для текущей версии: `release/v1.5.0`.
